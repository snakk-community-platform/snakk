Journal discussions are for ongoing, chronological updates. Unlike a standard discussion where replies are responses, journal entries are authored by the original poster as a running log.

## When to use it

- Project progress logs ("Building my first PC — Day 1, Day 2...")
- Travel diaries
- Learning journals ("My journey learning Go")
- Ongoing event coverage

## How it works

1. Create a Journal discussion with a title describing the overall topic
2. Write your first entry as the opening post
3. Add new entries over time — each one is a new post, marked as a journal entry
4. Entries are displayed chronologically, giving readers a timeline of your progress

Journal entries are distinguished from regular replies so readers can follow the author's narrative thread without getting lost in the comments.
