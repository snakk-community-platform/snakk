Question discussions are for when you need a specific answer. They include an accepted-answer workflow so the community can see which reply solved the problem.

## When to use it

- Technical questions ("How do I...?")
- Troubleshooting ("My X isn't working, what's wrong?")
- Recommendations ("What's the best tool for...?")
- Any question where one reply can be marked as the definitive answer

## How it works

1. Create a Question discussion with your question as the title
2. Add context and details in the body
3. Community members reply with answers
4. When a reply solves your problem, mark it as the **accepted answer**
5. The accepted answer is highlighted and pinned visually so future readers can find it quickly

## Accepted answers

Only the original author of the question can mark an answer as accepted. The accepted answer gets a visual indicator and appears prominently in the discussion. You can change the accepted answer at any time if a better one comes along.
