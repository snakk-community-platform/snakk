Snakk supports nine discussion types, each designed for a different kind of conversation. Space moderators control which types are available in their space.

| Type | Best for | Key feature |
|------|----------|-------------|
| **Standard** | General conversation | Rich text editor with markdown |
| **Question** | Getting help | Accepted answer workflow |
| **Poll** | Gathering opinions | Vote with results visualization |
| **Link** | Sharing URLs | Automatic oEmbed preview cards |
| **Images** | Sharing photos | Gallery with 6 layout options |
| **Debate** | Structured argument | Positions with per-side statistics |
| **Guide** | Tutorials and how-tos | Auto-generated table of contents |
| **Journal** | Running updates | Chronological entry format |
| **IAMA** | Ask Me Anything events | Scheduling, verification, and official answers |

Each type has its own dedicated article in this help section with full details on how to use it.
