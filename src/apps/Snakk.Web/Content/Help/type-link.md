Link discussions are for sharing and discussing URLs. Snakk automatically generates a rich preview card for the linked content.

## When to use it

- Sharing an article, blog post, or news story
- Discussing a video, podcast, or other media
- Linking to a tool, resource, or project

## Preview cards

When you paste a URL, Snakk fetches metadata from the site and builds a preview card showing:

- **Title** and description from Open Graph / meta tags
- **Thumbnail image** (cached locally for fast loading)
- **Domain name** so you know where the link goes
- **oEmbed content** for supported providers — YouTube videos, tweets, and more play inline

Supported oEmbed providers include YouTube, Vimeo, TikTok, Twitter/X, Bluesky, Reddit, Spotify, SoundCloud, Bandcamp, Twitch, Imgur, CodePen, and Canva.

## Discussion body

You can add your own commentary below the link preview using the standard markdown editor. This is a good place to highlight key points, share your take, or provide context.
