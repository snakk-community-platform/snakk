Discussions are the core of Snakk. To start one, click **New Discussion** in the sidebar (you need to be signed in).

## Choosing a space

Every discussion lives in a space. When you create a new discussion, you'll first select which space to post in. Each space may allow different discussion types — if a type isn't available, the space moderators have restricted it.

## Choosing a type

After selecting a space, you'll see a picker showing all available discussion types. Each type has a brief description. Pick the one that best fits what you want to share or discuss.

## Writing your content

All discussion types include a title field. Most also have a rich text editor for your content body, which supports markdown formatting, image uploads, and inline code blocks.

Some types have additional fields:

- **Poll** — add poll options, configure multi-vote and secret ballot settings
- **Images** — upload images, choose a gallery layout
- **Debate** — define the positions people can argue for
- **Link** — paste a URL (a preview is generated automatically)
- **IAMA** — set a schedule and verification details

## Tips

- Use a clear, descriptive title — it's the first thing people see
- Choose the right discussion type for your content. A question will get better answers than a standard post if you're genuinely looking for help
- You can format your content with markdown — see the Markdown Guide for syntax
- Draft content is saved automatically. If you navigate away and come back, your title and content are preserved
