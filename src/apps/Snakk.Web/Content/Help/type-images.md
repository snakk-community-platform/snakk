Image discussions let you share one or more images with the community. Snakk supports multiple gallery layouts, image comparison, and spoiler tagging.

## When to use it

- Sharing photography, artwork, or screenshots
- Before/after comparisons
- Visual tutorials or step-by-step guides
- Memes and visual content

## Uploading images

Drag and drop images into the upload area, or click to browse. Images upload immediately and you can reorder them by dragging. Supported formats: JPEG, PNG, and WebP. All images are automatically converted to WebP for optimal file size.

## Gallery layouts

When you have multiple images, you can choose from six layout options:

| Layout | Description |
|--------|-------------|
| **Grid** | Uniform grid of thumbnails |
| **Masonry** | Pinterest-style columns that preserve aspect ratios |
| **Justified** | Rows of images with consistent heights |
| **Carousel** | One image at a time with prev/next navigation |
| **Hero** | First image large, rest in a small grid below |
| **Compare** | Before/after slider (exactly 2 images) |

The compare layout is only available when you have exactly two images. Use the swap button in the top-left corner to switch the before and after positions.

## Spoiler tagging

If your images contain spoilers, you can tag them. Spoiler-tagged images are blurred until the viewer explicitly clicks to reveal them.

## In the feed

Image discussions show a preview in the discussion list. The preview adapts its height to match the image's aspect ratio — wide panoramic images appear as thin strips, tall portraits are capped at a reasonable height.
