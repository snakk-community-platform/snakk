Standard discussions are the default conversation format. They work like a traditional forum thread — you write a title and body, and others reply.

## When to use it

- General conversation that doesn't fit a more specific type
- Announcements and updates
- Sharing thoughts, stories, or opinions
- Starting an open-ended discussion

## Features

- Full markdown editor with formatting toolbar
- Inline image uploads
- Code blocks with syntax highlighting
- Spoiler tags for hidden content
- Replies can be threaded (reply to a specific post)

## Writing your post

Type a descriptive title, then write your content in the editor. You can use markdown for formatting, upload images by dragging them into the editor, and add code blocks with syntax highlighting.
